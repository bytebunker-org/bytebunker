## Webcam Discovery (OSINT Methods)

### IoT Search Engines

| Tool | Query for Trier | URL |
|---|---|---|
| **Shodan** | `webcam country:DE city:Trier` | https://www.shodan.io/ |
| **Shodan** (RTSP) | `port:554 has_screenshot:true country:DE city:Trier` | |
| **Censys** | `labels:"camera" and location.country_code="DE" and location.city="Trier"` | https://search.censys.io/ |
| **Insecam** | Browse by city | http://www.insecam.org/en/bycity/Trier/ |
| **FOFA** | `title="Network Camera" && country=="DE" && city=="Trier"` | https://fofa.info/ |
| **Netlas** | `protocol:rtsp AND geo.country:DE` | https://netlas.io/ |
| **ZoomEye** | `app:"webcam" country:"DE"` | https://www.zoomeye.ai/ |

### OpenStreetMap Camera Mapping

Paste into https://overpass-turbo.eu/ to find all mapped surveillance cameras around Trier (20km radius):

```
[out:json][timeout:25];
node["man_made"="surveillance"](around:20000,49.7596,6.6441);
out body;
```

Visualization tools:
- **OSM-Camera Map:** https://osmcamera.dihe.de/ (219,000+ cameras worldwide)
- **Surveillance under Surveillance:** https://sunders.uber.space/ (hourly OSM updates)

### RTSP Discovery

Common URL patterns for IP cameras:
```
rtsp://<ip>:554/stream
rtsp://<ip>:554/live.sdp
rtsp://<ip>:554/h264/ch01/main/av_stream   (Hikvision)
rtsp://<ip>:554/onvif1                       (ONVIF generic)
```
